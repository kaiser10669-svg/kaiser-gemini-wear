================================================================================
   НАБОР ДЛЯ АКТИВАЦИИ GOOGLE GEMINI И ПЕРЕНОСА АККАУНТОВ НА XIAOMI WATCH 5
                  Разработано Kaiser & Antigravity для 4PDA
================================================================================

Содержимое папки:
1. activate_gemini.py       - Основной скрипт активации Google Gemini (Assistant).
2. run_gemini_activation.bat - Запуск активации Gemini в один клик.
3. rfcomm_bridge.jar        - Мост Bluetooth RFCOMM -> TCP для телефона (без root).
4. start_phone_bridge.bat   - Скрипт быстрой загрузки и запуска моста на телефоне.
5. MiHealthBridge.apk       - Вспомогательное приложение DirectTransfer (AOSP Signed)
                              для переноса Google-аккаунтов через эмулятор.
6. transfer_account.py      - Скрипт переноса Google-аккаунта на часы.
7. run_account_transfer.bat - Запуск переноса аккаунта.

--------------------------------------------------------------------------------
БЫСТРЫЙ СТАРТ: КАК АКТИВИРОВАТЬ GEMINI (ЕСЛИ АККАУНТ УЖЕ НА ЧАСАХ)
--------------------------------------------------------------------------------
1. Включите на часах и телефоне «Отладку ADB по Wi-Fi» в меню разработчика.
2. Подключите часы к компьютеру: adb connect IP_ЧАСОВ:5555
3. Запустите start_phone_bridge.bat, введите IP телефона и Bluetooth MAC часов.
   (Мост запустится в фоновом режиме на телефоне).
4. Запустите run_gemini_activation.bat и следуйте подсказкам на экране.
5. Через 5 секунд на часах откроется полноценный рабочий экран Google Gemini!

--------------------------------------------------------------------------------
БЫСТРЫЙ СТАРТ: КАК ДОБАВИТЬ ВТОРОЙ GOOGLE АККАУНТ
--------------------------------------------------------------------------------
1. Запустите эмулятор Android Studio с образом Google Play.
2. Войдите в эмуляторе в Google-аккаунт, который нужно перенести.
3. Установите PIN экрана в эмуляторе: adb -s emulator-5554 shell locksettings set-pin 1234
4. Установите MiHealthBridge.apk: adb -s emulator-5554 install -r MiHealthBridge.apk
5. Запустите run_account_transfer.bat.
6. Аккаунт появится в меню «Настройки -> Аккаунты» на часах.
